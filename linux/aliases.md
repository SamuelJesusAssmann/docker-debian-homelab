# Docker Compose Aliases

## Alias Configuration

Added custom aliases to improve Docker workflow productivity.

```bash
alias dc='docker compose'
alias dps='docker ps'
```

## Usage Examples

### Start containers

```bash
dc up -d
```

### Stop containers

```bash
dc down
```

### View running containers

```bash
dc ps
```

## Benefits

- Faster command execution
- Cleaner terminal workflow
- Improved operational efficiency
