# Linux Logs & Monitoring

Logs are records generated by the operating system and services to provide information about:
- system activity
- errors
- warnings
- service behavior
- troubleshooting events

Monitoring helps identify:
- failures
- high resource usage
- service interruptions
- infrastructure problems

Logs are critical in:
- Linux administration
- cloud infrastructure
- DevOps
- support engineering
- troubleshooting

---

# Viewing System Logs

## journalctl

View system logs:

```bash
journalctl
```

---

# Viewing Service Logs

Check logs from a specific service:

```bash
journalctl -u docker
```

Example:
- Docker startup errors
- failed services
- infrastructure troubleshooting

---

# Real-Time Logs

Follow logs live:

```bash
journalctl -u docker -f
```

Useful during:
- debugging
- troubleshooting
- service monitoring

---

# Viewing File Logs

Read log files manually:

```bash
cat /var/log/syslog
```

View large logs:

```bash
less /var/log/syslog
```

---

# tail Command

View latest log entries:

```bash
tail /var/log/syslog
```

Follow logs in real time:

```bash
tail -f /var/log/syslog
```

---

# Monitoring System Resources

## top

Monitor CPU and memory usage:

```bash
top
```

---

# htop

Interactive monitoring tool:

```bash
htop
```

Install:

```bash
sudo apt install htop
```

---

# Important Log Locations

| Directory | Purpose |
|---|---|
| /var/log | System logs |
| /var/log/syslog | General system logs |
| /var/log/auth.log | Authentication logs |
| /var/log/dpkg.log | Package installation logs |
